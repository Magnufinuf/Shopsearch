# Shopify-appen (oppsett)

`shopify.app.toml` er oppsettet for den offentlige Scavenger-appen i Shopify
(adresser, tilgang og webhooks, inkludert personvern-varslene).

Endrer du noe her, last det opp fra denne mappen med:

```
npx @shopify/cli@latest app deploy
```

(På Windows i PowerShell: `npx.cmd @shopify/cli@latest app deploy`.)
